# ZapCart Security Policy

## Reporting a vulnerability

Please report security issues privately to the repository maintainer through GitHub. If private vulnerability reporting is enabled for this repository, use its **Security** tab to submit a report. Otherwise, contact the maintainer directly on GitHub. Please do not publish suspected vulnerabilities or sensitive details in a public issue.

Include a description of the issue, steps to reproduce it, and its potential impact. Avoid accessing, changing, or deleting data that is not yours while investigating.

## Project limitations

ZapCart is a browser-based demo, not a production service. Its login/OTP, checkout, coupons, payments, and order tracking are simulated in the browser. They do not provide real authentication, payment processing, or order fulfillment. Do not enter real credentials, payment details, or other sensitive information.
